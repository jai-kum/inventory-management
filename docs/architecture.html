Architecture overview

Factory Inventory Management System

A two-tier demo app. A Vue 3 single-page app on port 3000 calls a read-only FastAPI service on port 8001. The service filters data held in memory, loaded from JSON files at startup. There is no database, no authentication and no write path for business data.

Data flow

Example: a user picks "Tokyo" and "Q2-2025" on the Dashboard. Every filtered view follows the same path.

  1. The user changes a dropdown in FilterBar. It writes to module-level refs in useFilters, which are singletons shared by every view. components/FilterBar.vue · composables/useFilters.js
  2. The active view runs a watch on the four filter refs, which calls its loadData(). views/Dashboard.vue:676
  3. getCurrentFilters() renames location to warehouse and period to month. api.js leaves out any value set to all. client/src/api.js
  4. axios sends cross-origin requests in parallel, for example GET :8001/api/orders?warehouse=Tokyo&month=Q2-2025. CORS allows them. Dashboard calls summary, orders, inventory and backlog together
  5. The handler calls apply_filters, which matches warehouse exactly and category and status case-insensitively. It then calls filter_by_month, which expands quarters through QUARTER_MAP and does a substring match on order_date. server/main.py
  6. The response_model validates the filtered list and FastAPI returns JSON. Dashboard KPIs, such as inventory value and low-stock count, are computed per request. server/main.py · get_dashboard_summary
  7. The view stores the raw arrays in refs. Computed properties derive the KPIs, charts and tables. formatCurrency converts USD to JPY at a fixed rate of 150 when the locale is ja. views/*.vue · utils/currency.js

Startup sequence

  1. python main.py imports mock_data, which reads all 7 JSON files into module-level lists.
  2. uvicorn serves the app on 0.0.0.0:8001.
  3. Vite serves the SPA on port 3000. main.js registers 6 routes and mounts App.vue.
  4. App.vue requests /api/tasks on mount. That request returns 404, and the error is caught and logged.

What filters affect

  • Orders and dashboard: all 4 filters
  • Inventory: warehouse and category only
  • Demand, backlog, spending and reports: no server-side filtering

Findings

These came up while reading the code. None of them stop the app from running.

Gap

The tasks modal calls /api/tasks, which the server never defines, so it returns 404. Only the 4 seeded mock tasks from useAuth work. Adding or toggling a non-seeded task fails, and the error is only logged to the console.

App.vue:91–138 · api.js · main.py
Orphan

Backlog.vue exists and watches filters, but no route points to it. Backlog data appears only through the Dashboard and BacklogDetailModal. The purchase-order helpers in api.js have no route and no callers, and purchase_orders.json is empty, so has_purchase_order is always false.

main.js · views/Backlog.vue · data/purchase_orders.json
Inconsistent

Reports.vue uses the Options API, hardcodes http://localhost:8001 through raw axios, ignores the global filters and skips i18n (its "Reports" nav label is hardcoded). The project guidelines call for the Composition API and for routing every call through api.js.

views/Reports.vue:128–173 · App.vue:26
Logic

The dashboard summary's total_backlog_items ignores every filter. The date filters are hardcoded to 2025, in both QUARTER_MAP and the FilterBar options, and the quarter logic appears twice in main.py.

main.py · get_dashboard_summary · get_quarterly_reports
Stale

generate_data.py generates "Widgets" and "Components" products. Those categories don't match the current data (Circuit Boards, Sensors, Actuators, Controllers, Power Supplies), so running it would overwrite the data with records the FilterBar can't filter.

server/generate_data.py
Config

The API base URL is hardcoded in two places, and there's no Vite proxy or environment variable. CORS combines allow_origins=["*"] with allow_credentials=True, which is fine for a local demo but too permissive for anything deployed.
